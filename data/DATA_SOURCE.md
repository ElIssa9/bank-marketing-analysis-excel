# Dataset source and reuse

- Dataset: UCI Bank Marketing, ID 222.
- Selected file: `bank-additional/bank-additional-full.csv`, from the nested `bank-additional.zip` in the public download archive.
- Repository page: https://archive.ics.uci.edu/dataset/222/bank+marketing
- Download archive: https://archive.ics.uci.edu/static/public/222/bank+marketing.zip
- Citation: Moro, S., Rita, P., & Cortez, P. (2014). Bank Marketing [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5K306
- Associated paper: Moro, S., Cortez, P., & Rita, P. (2014). A Data-Driven Approach to Predict the Success of Bank Telemarketing. Decision Support Systems, 62, 22–31. https://doi.org/10.1016/j.dss.2014.03.001
- License stated by UCI: Creative Commons Attribution 4.0 International (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/
- Retrieved: 25 October 2026.
- Period described by the source: May 2008–November 2010.
- Institution: an unnamed Portuguese banking institution. The data is not identified as Arab Bank data.
- Size: 41,188 records and 21 columns (20 input attributes and one outcome).
- Delimiter: semicolon. Numeric values use a decimal point.
- Raw CSV SHA-256: `74adfc578bf77a7ff4bb1ba4a9f8709d9e3c6907342959c2c8416847e0afb4d8`.

The included CSV is an unchanged extraction of the selected file. The Excel project adds four calculated columns, native PivotTables, dashboard charts and interpretation. These transformations are documented in the build guide.

The data license permits sharing and adaptation with appropriate attribution, a license link and an indication of changes. It does not imply the source creators or the bank endorse this project. Retain this attribution when redistributing the data or workbook.
