# Native Excel workbook handoff

The live workbook has been built in Microsoft Excel for Mac with four worksheets, 10 native PivotTables, 10 editable charts and the full source data.

Before publishing, save the open workbook into this folder as:

`Bank_Marketing_Analysis.xlsx`

The connected Excel tools used to build the workbook do not advertise a save/export command. The user must complete this save in Excel. Screenshots and numerical validation are included separately, but they do not replace the native workbook.

After saving, open the saved file and confirm that the Dashboard, Analysis, Bank_Data and Data_Dictionary sheets are present. The expected baseline is 41,188 records, 4,640 subscriptions and 11.27% subscription rate.
